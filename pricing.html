FAQ

Common questions

What counts as a "conversation"?

Each time a user sends a message and the chatbot replies is counted as one conversation (one API call). A typical visitor asking 3–4 questions uses 3–4 conversations. The welcome message shown when the chat opens does not count.

What happens if I exceed my monthly limit?

The chatbot keeps working. Overages are billed at $0.011 per additional message. You'll see the overage in next month's invoice. We'll notify you if you're approaching your limit.

Is there a setup fee?

Plans only cover the monthly infrastructure + AI costs. Initial setup — which includes Google OAuth, knowledge base creation, widget customization, and website embedding — is quoted separately as a one-time project fee.

Can I switch plans mid-month?

Yes, you can upgrade or downgrade at any time. Upgrades take effect immediately. Downgrades take effect at the start of your next billing cycle.

Why does the knowledge base affect Claude API cost?

Every chat message includes your entire knowledge base as context (system prompt) so the AI can answer accurately about your business. A detailed knowledge base is ~1,500–2,500 tokens, which is sent with every request. Larger knowledge bases = slightly higher cost per message.

Does the mic / voice input work on all browsers?

Voice input works on Chrome (desktop + Android) and Safari (iOS 15+). It is automatically hidden on browsers that don't support it. On WordPress sites that block the microphone via security headers, we provide a fix as part of setup.
